# Fotky do dokumentu

Webová aplikace, která z fotek dokumentů rozpozná text (OCR přímo v prohlížeči přes Tesseract.js) a uloží ho jako upravitelný dokument do **PDF**, **DOCX** (Word) nebo **ODT** (OpenOffice/LibreOffice).

**Spustit:** https://fidlip.github.io/photo-to-doc/

- fotky nikam neodcházejí, vše běží v prohlížeči
- vyfocení přímo z mobilu, výběr z galerie, vložení ze schránky
- jazyky: čeština, slovenština, angličtina, němčina
- rozpoznaný text jde před exportem upravit (`# nadpis`, `- odrážka`, `**tučně**`, `| tabulka |`)
